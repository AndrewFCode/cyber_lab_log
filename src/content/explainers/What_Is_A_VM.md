A VM is shorthand for virtual machine. 

A virtual machine works as multiple servers in one place, without the need of having loads of servers.   
A laptop can be turned into a Virtual machine meaning that a user can set up multiple workstations using the one laptop.

This is a software based computer that shares the physical elements of the actual laptop, but can run multiple machines from that one physical machine.
