Walkthroughs of the **Learn Windows PowerShell** labs. Each heading is a command (or a short sequence). Drop a screenshot under it so you can see what happened.

## How to add a screenshot

1. Save the PNG or JPG into `public/media/labs/` (for example `public/media/labs/powershell-get-date.png`).
2. In this file, add the image on its own line:

```markdown
![Get-Date in PowerShell](/media/labs/powershell-get-date.png)
```

The path always starts with `/media/labs/` — that folder is what GitHub Pages and Pages CMS serve.

## Example lab

Replace this with a real lab. Keep the command in a code block, then the screenshot.

```powershell
Get-Date
Get-Host
```
