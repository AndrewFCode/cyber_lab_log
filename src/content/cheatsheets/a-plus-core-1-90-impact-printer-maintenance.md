> **In one line:** keep a dot-matrix printer running by swapping the ribbon when output fades, replacing the print head when pins fail (cool first), and loading continuous tractor-feed paper with both hole and form alignment checked.

*Companion to: Professor Messer A+ Core 1 (220-1201), Section 3, objective 3.8.* The full version is the Impact Printer Maintenance class notes; the section overview is the Section 3 sheet. See the Impact printers lesson for how they work.

## Maintenance tasks

| Task | Key points |
| --- | --- |
| Ribbon | **Fading** output = worn ribbon; **modular cartridge** — pop out, push in, **under a minute** |
| Print head | Mechanical; **pins fail** over time. **Let it cool** if recently used (heat sink on back). Removed via **screws** or a tool-free **release lever/bar**. Replace ribbon at the same time for best combined result |
| Paper | **One continuous** tractor-feed sheet, not sheets. Align **holes** on **both sides**; align carefully to any **pre-printed form**. Keep the **whole path** (in and out) clear — an obstruction causes the paper to readjust and **jam** |

## Fix by symptom

```
Output fading           -> replace ribbon cartridge
Same dot missing always -> print head pin failure -> replace head
Repeated jams            -> check paper path (in + out) for obstructions
```

## 🔐 Security notes

- **A worn ribbon/head is an availability problem for the process it supports** (delivery notes, pick tickets) — monitor these consumables like laser toner or inkjet nozzles.
- **Pre-printed forms are controlled documents:** misalignment can put data in the wrong field — a data-integrity issue, not just a cosmetic one. Test-print after any maintenance before a production run.
- **Dispose of removed ribbons securely** — they physically retain everything printed (per the Impact printers lesson); a spent print head carries no data.

## Practice drills

<details>
<summary>1. Why does dot-matrix output fade over time?</summary>

The ribbon loses ink as it repeatedly cycles through the printer.
</details>

<details>
<summary>2. What tells you it's time to replace the ribbon, and how long does it take?</summary>

Output getting progressively lighter/hard to read; the swap usually takes under a minute.
</details>

<details>
<summary>3. What caution applies before handling a recently used print head?</summary>

Let it cool first — print heads run warm and the back is essentially a heat sink.
</details>

<details>
<summary>4. Two ways a print head is removed?</summary>

A few screws, or a tool-free release lever/bar, depending on the model.
</details>

<details>
<summary>5. What's different about dot-matrix paper vs laser/inkjet paper?</summary>

It's one continuously fed piece with tractor-feed holes on both sides, not individual sheets.
</details>

<details>
<summary>6. Two alignment checks when loading continuous paper?</summary>

Tractor-feed holes on both sides, and the print position against a pre-printed form's fields.
</details>

<details>
<summary>7. What causes a continuous-feed printer to jam?</summary>

Something obstructing the paper's path in or out, causing it to readjust itself and jam.
</details>

## Key takeaways

- **Fading = ribbon**, swap the modular cartridge fast.
- **Consistent missing dots = failed pin**, replace the head (cool first); swap the ribbon too while it's open.
- **Continuous paper:** align holes both sides, align to any pre-printed form, keep the whole path clear.
- **Security:** treat ribbon/head as monitored consumables; verify form alignment for data integrity; dispose of ribbons securely.
